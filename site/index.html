Peer2Peer File Share Site This site is for sending files without size restrictions to people (one person at a time) without the need for a server to handle the transfer. One person needs to be the host for the transfer, the other is the sender. This does mean that files can only be transfered one way with each pair of URLs (for now). Any number of files can be sent with one session, but only one file can be sent at a time. Click the button below to load the host page, it will generate the sender URL that pairs with it. Host pages can be reused, but it is not recommended to. Host File Transfer
